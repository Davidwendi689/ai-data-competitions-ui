## 1. 推荐整体方案

上传链路：

`用户选择图片 → 前端检查大小/类型 → 前端压缩成 WebP/JPEG → 上传压缩后文件 → 后端二次压缩与校验 → 存储 thumb/medium/large → 前端只展示合适尺寸`

不要直接把原图塞进 `<img>` 预览，也不要转 base64。用 `URL.createObjectURL()`，并且预览压缩后的 Blob。

Node/Next.js 后端建议用 `sharp`。Sharp 官方定位就是高性能 Node 图像处理，可以把常见图片转成 JPEG、PNG、WebP、AVIF 等 Web 友好格式；它也提供 `limitInputPixels` 这种输入像素限制，适合防止超大图造成内存问题。([sharp][1]) ([sharp][2])

前端可以手写 Canvas 压缩，也可以先用 `browser-image-compression`。它支持在浏览器侧压缩 JPEG/PNG/WebP/BMP，并支持 Web Worker，能避免主线程卡死。([GitHub][3])

## 2. 第一版参数直接定死

建议后台业务图、头像、作品图统一用下面规则：

| 场景    |    最长边 |  目标大小 | 格式   |        质量 |
| ----- | -----: | ----: | ---- | --------: |
| 头像    |  512px | 150KB | WebP |      0.75 |
| 普通内容图 | 1280px | 500KB | WebP | 0.75–0.82 |
| 作品展示图 | 1920px | 900KB | WebP | 0.78–0.85 |
| 缩略图   |  320px |  80KB | WebP |       0.7 |

硬限制：

```ts
const IMAGE_LIMITS = {
  maxOriginalSizeMB: 10,
  maxPixels: 24_000_000, // 例如 6000x4000
  maxWidth: 1920,
  maxHeight: 1920,
  targetSizeKB: 800,
  minQuality: 0.55,
  startQuality: 0.82,
};
```

超过这些直接拒绝或要求用户换图：

```ts
if (file.size > 10 * 1024 * 1024) {
  throw new Error("图片过大，请上传 10MB 以内的图片");
}
```

## 3. 前端压缩算法

核心算法：

1. 读取图片尺寸；
2. 如果最长边超过限制，按比例缩小；
3. 画到 Canvas；
4. 用 `canvas.toBlob()` 输出 WebP/JPEG；
5. 如果结果仍然超过目标大小，就逐步降低质量；
6. 上传压缩后的 Blob/File。

`HTMLCanvasElement.toBlob()` 本身就是浏览器标准 API，用于把 Canvas 内容输出为 Blob 图片对象。([MDN Web Docs][4]) `createImageBitmap()` 可以异步从图片源创建位图对象，比直接塞进 DOM 里预览更适合做处理流程。([MDN Web Docs][5])

前端核心代码：

```ts
type CompressOptions = {
  maxWidth?: number;
  maxHeight?: number;
  targetSizeKB?: number;
  mimeType?: "image/webp" | "image/jpeg";
  startQuality?: number;
  minQuality?: number;
};

export async function compressImage(
  file: File,
  options: CompressOptions = {}
): Promise<File> {
  const {
    maxWidth = 1920,
    maxHeight = 1920,
    targetSizeKB = 800,
    mimeType = "image/webp",
    startQuality = 0.82,
    minQuality = 0.55,
  } = options;

  if (!file.type.startsWith("image/")) {
    throw new Error("只能上传图片文件");
  }

  if (file.size > 10 * 1024 * 1024) {
    throw new Error("图片过大，请上传 10MB 以内的图片");
  }

  const bitmap = await createImageBitmap(file);

  const originalWidth = bitmap.width;
  const originalHeight = bitmap.height;
  const originalPixels = originalWidth * originalHeight;

  if (originalPixels > 24_000_000) {
    bitmap.close();
    throw new Error("图片分辨率过高，请上传 2400 万像素以内的图片");
  }

  const scale = Math.min(
    1,
    maxWidth / originalWidth,
    maxHeight / originalHeight
  );

  const targetWidth = Math.round(originalWidth * scale);
  const targetHeight = Math.round(originalHeight * scale);

  const canvas = document.createElement("canvas");
  canvas.width = targetWidth;
  canvas.height = targetHeight;

  const ctx = canvas.getContext("2d");
  if (!ctx) {
    bitmap.close();
    throw new Error("浏览器不支持图片压缩");
  }

  ctx.drawImage(bitmap, 0, 0, targetWidth, targetHeight);
  bitmap.close();

  let quality = startQuality;
  let blob = await canvasToBlob(canvas, mimeType, quality);

  const targetBytes = targetSizeKB * 1024;

  while (blob.size > targetBytes && quality > minQuality) {
    quality -= 0.07;
    blob = await canvasToBlob(canvas, mimeType, quality);
  }

  const ext = mimeType === "image/webp" ? "webp" : "jpg";
  const basename = file.name.replace(/\.[^.]+$/, "");

  return new File([blob], `${basename}.${ext}`, {
    type: mimeType,
    lastModified: Date.now(),
  });
}

function canvasToBlob(
  canvas: HTMLCanvasElement,
  type: string,
  quality: number
): Promise<Blob> {
  return new Promise((resolve, reject) => {
    canvas.toBlob(
      (blob) => {
        if (!blob) reject(new Error("图片压缩失败"));
        else resolve(blob);
      },
      type,
      quality
    );
  });
}
```

上传时这样用：

```ts
async function handleUpload(file: File) {
  const compressed = await compressImage(file, {
    maxWidth: 1920,
    maxHeight: 1920,
    targetSizeKB: 800,
    mimeType: "image/webp",
  });

  const formData = new FormData();
  formData.append("file", compressed);

  await fetch("/api/upload/image", {
    method: "POST",
    body: formData,
  });
}
```

## 6. 前端展示端也要限流

后台作品墙、用户列表、内容列表，统一规则：

```tsx
<img
  src={image.thumbUrl}
  loading="lazy"
  decoding="async"
  width={160}
  height={160}
  alt=""
/>
```

详情页才用：

```tsx
<img
  src={image.largeUrl}
  loading="lazy"
  decoding="async"
  alt=""
/>
```

如果你用 Next.js，可以接入 `next/image`，但前提是你已经在上传阶段生成了干净的多规格图片。不要把优化压力全部丢给展示端。

## 7. 最小可行版本

你现在第一版可以这样落地：

前端：

```bash
npm install browser-image-compression
```

```ts
import imageCompression from "browser-image-compression";

export async function compressBeforeUpload(file: File) {
  return await imageCompression(file, {
    maxSizeMB: 0.8,
    maxWidthOrHeight: 1920,
    useWebWorker: true,
    fileType: "image/webp",
    initialQuality: 0.82,
  });
}
```
