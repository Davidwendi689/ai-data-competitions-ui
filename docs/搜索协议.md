源码核对：2026-10-15，Web `0b0d594952897ea1d90c39b7afb5b7430571f078`，API `d9a789baed9f45ce033f97da5c627eb4cbcc8dee`。统一搜索 Epic [Web #8](https://github.com/gduf-community/ai-data-competitions-ui/issues/8) 及 8 个子任务已关闭；本页描述当前实现。生产投影/回填、资源和真机证据按原记录分别维护，Issue 完成不改变运行开关。

## 哪个入口负责搜索

| 场景 | 数据来源与搜索位置 | 分页/范围 |
| --- | --- | --- |
| `/competitions` | SSR 调 API `/api/competitions?search=1` | API 全局匹配、排序后分页，不在浏览器过滤当前页 |
| `/competitions/[id]/questions` | SSR 调 `/api/questions?search=1&competitionId=...` | 固定比赛作用域，排除隐藏内容，再匹配/排序/分页 |
| 管理用户、报名 | 原有 API 完整授权集合；keyword/q 在 API 中处理 | 不接受公共 page/pageSize，不伪装成远程分页 |
| `AdminDataTable` | 调用方提供完整授权数组时用纯函数匹配 | external/manual 分页不进行本地二次过滤/排序 |
| 安全态势事件 | 当前已加载的有界窗口/样本 | 明确标注当前样本；保留原事件顺序，不声称全库搜索 |
| 比赛选择器、首页展示 | 有界专用查询/精选 | 不能拿最多 20 项或精选集合代替完整搜索结果 |

传输策略禁止浏览器读取公开比赛/问答 JSON；URL 导航由 App Router 取得服务端页面。接口包裹见[HTTP 参考](./HTTP接口参考.md)。

## 公共参数

| 参数 | 默认 | 约束 |
| --- | --- | --- |
| `q` | 空串 | 普通模式原串及规范化结果都不超过 256 UTF-16 单元 |
| `mode` | `fuzzy` | fuzzy / exact；regex 仅在当前入口明确启用时可用 |
| `page` | 1 | 十进制安全正整数；上限 1,000,001，且偏移不得超过 1,000,000 |
| `pageSize` | 20 | 公共页 1–50 |
| `keyword` | 兼容旧入口 | 与 q 同时存在时值必须相同，否则拒绝；新链接由 serializeSearchQuery 收敛为 q |
| `year` | 比赛页取聚合年份中的最新年 | 显式值须为四位数字且不小于 1900；只用于比赛 |
| `status` | 不筛选 | 比赛使用 [publicCompetitionFilterStatuses](../src/lib/competition-status.ts)；问答只允许 open/closed |

`search=1` 是 Web 发给 API 的统一搜索分支标记，不要求用户在页面 URL 手写它。问答的 competitionId 来自页面路径；API 要求有效赛事 UUID，不允许页面查询参数换到另一个比赛。重复标量参数、指数/小数/负数分页、未知 mode 或非法筛选返回参数错误。页码超过结果末页返回空 items，总数保持真实值，不悄悄截到最后一页。

比赛页先调用 `limit=1` 获取年份聚合和 `searchCapabilities.regex`，再请求当前页；Flight 仅携带当前查询所需数据。切换年份/状态/搜索词重置 page，翻页保留查询；默认最新年份写入导航链接，使分享/刷新保持选择。

## 普通比较与排序

[search.ts](../src/lib/search.ts) 仅处理比较副本，不改写原文或身份键：

1. fuzzy/exact 都执行 NFKC、首尾 trim、非 locale 小写；fuzzy 另外折叠内部空白，exact 保留内部空白。
2. fuzzy 对单字段的完整/前缀/子串/全部 token/部分 token 分别计 100/80/60/40/20；exact 只接受完整字段相等。
3. 字段得分乘静态权重，最终取最高字段分，不累加；token 不跨字段拼接，数组元素也不拼接。普通 `%`、`_`、`.`、`*` 等按字面字符处理。
4. 比赛 title/category/department 权重 10/5/3，问答 title/body 权重 10/3。非空词先按得分，再按域排序与二进制 ID 兜底；比赛按报名开始时间升序，问答按置顶/创建时间降序。空词保留筛选与域默认顺序。

内存适配 `searchInMemory` 要求 `kind:'complete'` 与唯一 ID，先对完整集合评分/排序再分页。远程一页或截断样本不能作为 complete 输入。

## 输入、URL 与取消

[SearchQueryForm](../src/components/shared/search-query-form.tsx) 与 [search-input](../src/lib/search-input.ts) 负责公共输入生命周期：250ms 防抖使用 replace，显式提交/筛选/清空使用 push，IME 组合期不提交，清空后恢复焦点，卸载清理定时器。首屏、Back/Forward 和刷新以 URL 为准，表单 key 绑定完整查询/筛选，避免晚到导航覆盖新输入。

SSR 请求使用既有 HTTP 传输，客户端资源读取使用 AbortController 和当前 URL/revision 检查；取消不显示普通失败。不能据代码或模拟 composition 测试声称所有操作系统输入法已实测。

## 受限正则

默认 `SEARCH_REGEX_ENABLED=false`。公共页面要求 **Web 运行时开关为 true、API 同名开关启用、API 能力声明为 true**；后台敏感检索与本地完整表格不开放此模式。能力未提供时明确返回 `UNSUPPORTED_SEARCH_MODE`，不静默回退普通搜索。

当前语法由 [search-regex.ts](../src/lib/search-regex.ts) 决定：

- 保留原始 Unicode、大小写与空白，不做 NFKC/trim/lower；空串无筛选得分 0，单个空格是有效模式。
- 支持字面字符、首尾 `^/$`、点、有限字符集合及 `{n}` / `{n,m}` 有界重复；集合不含范围/否定，重复上限 16。
- 不支持 flags、分组、分支、回溯引用、字符类缩写、范围或 `* / + / ?` 无界/简写量词；需要字面特殊字符时按该解析器支持的转义处理。
- 模式最多 128 UTF-16 单元、32 原子、64 状态；纯匹配器另有单字段 16,384 码点、完整源 1,000 行/1 MiB 文本限制。这些是代码预算，不是生产吞吐保证。

浏览器只做语法检查；公开候选搜索在 API 执行。不在主线程构造用户模式的原生 RegExp，不依赖产品 Worker，不放宽 CSP。SQL/超时/候选预算由 API 另行约束，预算超限不返回截断的 total。

## 返回与错误

统一纯结果为 `SearchResult<T>={items:[{item,score,matchedFields}],total,query}`；比赛/问答 HTTP 另外提供对应 `competitions/questions` 数组与域元数据。使用该响应的 total，不能按当前 items.length 计算全量命中。

| code / 状态 | 展示与恢复 |
| --- | --- |
| INVALID_QUERY / QUERY_TOO_LONG · 400 | 展示参数原因与重置入口 |
| UNSUPPORTED_SEARCH_MODE · 400 | 该入口/当前开关未启用，保留条件供选择普通模式 |
| INVALID_REGEX / REGEX_TOO_LONG / UNSUPPORTED_REGEX_SYNTAX · 400 | 标明语法或长度错误，不运行原生正则补救 |
| REGEX_CAPACITY_EXCEEDED / REGEX_TIMEOUT / SEARCH_TIMEOUT · 503 | 缩小条件或稍后重试，不显示部分计数 |
| SEARCH_NOT_READY · 503 | 投影或回填未就绪，显示准备中并可重试 |
| RATE_LIMITED · 429 | 稍后重试，沿响应 Retry-After |
| 其他服务/传输错误 | 保留错误页/重试，与成功空结果分开 |

后台 `/api/admin/search` 沿 target 的权限、允许字段、敏感精确检索及审计合同，页长最多 200；用户/报名原列表继续各自的完整集合合同。不要把公开 score、任意字段、公共 URL 分享或 regex 自动套到敏感后台搜索。
