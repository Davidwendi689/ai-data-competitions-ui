# 荣誉展示页面优化

## 接入范围

- `/awards`：年度总览，按后台真实年份展示比赛名及证书数量。
- `/awards?year=2026`：指定年份比赛；年份来自数据，不固定为 2026。
- `/awards?year=2026&competition=<id>`：比赛证书，保留等级分组、获奖人及原有证书详情链接。
- 无数据时显示空状态，不补造往年记录、数量或证书图片；后台接口和权限不变。
- 紧凑三级引导只给当前项及可返回的上级显示辅助文字。URL 支持刷新、分享和浏览器前进后退。
- 最新年度成果数字首次进入视野后滚动约 3 秒。减少动态效果设置及不支持 IntersectionObserver 时直接显示最终数字。
- 蓝色比赛卡片保留小幅鼠标磁吸反馈；触摸与减少动态效果模式不启用。
- 公共顶部导航改为白色横栏，小于 960px 使用展开式菜单，保留登录、通知、个人中心和按原角色规则显示的管理入口。
- 全局浅色底改为白色，奖状详情也使用白底；不删除网站原有深色模式。
