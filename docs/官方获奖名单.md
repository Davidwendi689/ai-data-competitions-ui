## 路由

| 路径 | 归属 | 说明 |
| --- | --- | --- |
| `/admin/official-awards` | Web #136 | 赛事入口列表（本 PR 不实现，仅提供导航入口） |
| `/admin/official-awards/competitions/[competitionId]` | **Web #138（本文档）** | 单赛事官方获奖名单 |

## 接口契约

页面只消费四个接口，字段定义集中在 `src/lib/contracts/official-awards.ts`。

```
GET   /api/admin/official-awards/competitions/{competitionId}
      ?year=&level=&subTrack=&q=&cursor=&limit=
GET   /api/admin/official-awards/competitions/{competitionId}/export
      ?view=award|member&format=csv|xlsx&<与列表相同的筛选>
PATCH /api/admin/official-awards/{awardId}        { expectedVersion, reason, levelCode?, subTrack?, teamName? }
POST  /api/admin/official-awards/{awardId}/void   { expectedVersion, reason }
```

BFF 白名单逐路径、逐方法放行，不使用 `/api/admin/**` 通配：

- `GET|HEAD .../competitions/{id}`
- `GET|HEAD .../competitions/{id}/export`
- `PATCH /api/admin/official-awards/{awardId}`
- `POST /api/admin/official-awards/{awardId}/void`

列表响应：

```jsonc
{
  "competition": { "id", "title", "edition", "years", "levels", "subTracks" },
  "items": [{
    "awardId", "version", "awardYear", "levelRaw", "levelCode", "subTrack",
    "teamName", "memberCount", "members": [{ "memberId", "name", "grade", "college", "major", "source" }],
    "advisors": [{ "name", "college", "source" }],
    "source", "sourceRef", "confirmedAt", "voided", "voidReason"
  }],
  "nextCursor", "hasMore",
  "summary": { "awardCount", "memberCount", "verifiedMemberCount", "draftPending" },
  "permissions": { "canExport", "canCorrect", "canVoid" },
  "lastUpdatedAt"
}
```

## 数据口径

正式事实**一奖一行**，不得以「一名学生一奖」计数：

| 指标 | 含义 |
| --- | --- |
| 奖项数 `awardCount` | 一条 award 记 1 项，团队奖不按人数放大 |
| 获奖人次 `memberCount` | 成员累加 |
| 去重人数 `verifiedMemberCount` | 按「姓名 + 学院」去重 |
| 草稿待处理 `draftPending` | 导入草稿数量，**不计入**正式事实，单独提示 |

等级同时保留 `levelRaw`（官方原文）与 `levelCode`（规范等级）；两者不一致时页面显示「规范：xxx」角标，便于对账。

## 导出

- 视图：`award`（一奖一行）、`member`（一学生一行）
- 范围：当前筛选的**全部**结果，不受分页影响
- 上限：500 项奖 / 5000 人次，超出返回 `413`，不静默截断
- 校验：`Content-Type` 必须是 `text/csv` 或 xlsx 类型；JSON/HTML 一律拒绝保存
- 文件名：取 `Content-Disposition` 的 `filename*`，缺失时回退默认名
- 取消：导出过程可用 `AbortController` 取消
- 安全：CSV 单元格以 `= + - @`、Tab、CR 开头的加前缀 `'`，防止公式注入

## 错误处理

| 状态 | 页面表现 |
| --- | --- |
| 401 | 提示登录失效 |
| 403 | 整页「没有权限」卡片，不展示空列表 |
| 404 | 「没有找到这场比赛」 |
| 409 | 版本冲突：保留输入、刷新列表、提示重新核对 |
| 413 | 提示超出导出上限并建议缩小范围 |
| 429 | 提示操作过于频繁 |
| 503 | 提示审计/服务暂不可用（审计拒绝时导出不落地） |

## 纠正与撤销

- 更正：`PATCH` 携带 `expectedVersion` 与必填 `reason`，成功后版本号 +1 并重新查询
- 撤销：`POST /void` 携带 `expectedVersion` 与必填 `reason`，只标记无效，不物理删除
- 两者都不调用个人奖状接口，不新增平行权限系统
- 按钮是否可见由列表返回的 `permissions` 决定，最终授权仍由 API 校验

## 隐私与缓存

- 列表与导出均走同源 BFF，响应 `Cache-Control: private, no-store`
- 页面不做 SSR 静态化，具名信息只经浏览器接口获取
- 仓库与本地联调均使用合成数据，不含真实学生或教师资料
