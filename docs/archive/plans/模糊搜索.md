# 18. 前端设计

## 18.1 列表页搜索组件

```text
AdminSearchToolbar
  ├─ KeywordInput
  ├─ FilterSelect
  ├─ DateRangePicker
  ├─ ResetButton
  └─ ExportButton
```

用户管理页示例：

```text
搜索框 placeholder:
搜索用户ID、昵称、完整邮箱、完整手机号
```

如果当前用户没有邮箱模糊搜索权限，不要提示“邮箱片段”。

## 18.2 URL query 同步

```text
/admin/users?keyword=zhangsan&page=1&pageSize=20&status=active
```

这样刷新、回退、复制链接都不会丢状态。

## 18.3 结果表格展示

普通管理员看到：

```text
ID    昵称      邮箱              手机号
1     张三      zh***@qq.com      138****5678
```

超级管理员可看到：

```text
ID    昵称      邮箱                  手机号
1     张三      zhangsan@qq.com       13812345678
```

但建议即使超级管理员，也可以默认脱敏，点击“查看明文”时再二次确认并记录审计。
