## 2. 当前信息架构边界

- 首页重点承接赛事曝光、荣誉展示和主入口导航，不再按旧模板逻辑堆叠通用营销区块。
- 比赛详情页已经承担“单个比赛的信息汇总页”职责，包含时间线、FAQ、问答、名人堂和经验展示。
- 个人中心已形成完整二级导航，不再只有“我的报名”，而是扩展为个人资料、成果、经验文章、名人堂资料等模块。
- 管理台已从单一审核后台扩展为“运营 + 分析 + 安全中心”的复合工作台。
- 社团源码仍分公开展示、个人中心内容工作台和平台审核台；2026-09-27取消审核、统一后台和封面必传目标尚未实施，见[社团说明](https://github.com/gduf-community/competition-Q-A-website/blob/d9a789baed9f45ce033f97da5c627eb4cbcc8dee/docs/modules/社团与内容管理.md)。
- 赛程安排页当前只是按比赛时间线聚合展示，不应写成完整日历或排班系统。
- 问答当前已是比赛维度的公开内容模块，但后台独立治理页仍不是现行主导航的一部分。

## 3. 学生侧主流程

### 发现比赛

1. 从首页、比赛列表或通知中心进入具体比赛。
2. 在比赛详情页查看时间线、FAQ、相关问答与往届展示。
3. 根据比赛配置执行官网报名或校内资料填报。
4. 在首页荣誉展示区点击奖状图片，可进入公开奖状详情页查看证书大图与关联比赛。
5. 也可进入 `/awards` 按年份和奖项级别浏览公开成果。

### 提交与跟踪

1. 在报名页完成个人或团队信息填写。
2. 提交后通过“我的报名”查看状态、详情与后续编辑入口。
3. 若被驳回或需要补充，可通过个人中心回到具体报名记录继续处理。

### 成果沉淀

1. 比赛结束后在“我的成果”上传奖状与补充获奖信息。
2. 获得管理员邀请草稿后，在“我的经验文章”编辑、提审并等待审核；个人自助创建当前拒绝。
3. 获得名人堂邀请后填写候选资料，由管理员激活后公开；个人自助创建当前拒绝。

### 社团内容维护

1. 被授予社团作用域的管理员从“我的社团”进入对应社团工作台。
2. 创建或编辑招新、活动、公告、活动总结等内容，并提交审核。
3. 平台审核通过后内容进入社团公开页；需要修改已发布内容时，先下线再编辑、重新提审。

## 4. 管理员侧主流程

### 运营主流程

1. 在比赛管理中创建或维护比赛。
2. 在通知管理中发布全站通知或比赛通知。
3. 在报名审核中处理提交、驳回、撤回与导出。
4. 在后台首页和数据看板中查看整体运行状态。

### 成果与人物主流程

1. 在奖状审核中审核学生上传的获奖证书。
2. 在经验文章审核中处理发布、驳回和下线。
3. 在名人堂管理中发送邀请、审核资料并维护展示顺序。
4. 在社团管理中维护社团管理员绑定，在社团内容审核中处理发布、驳回、下线和归档。

### 安全主流程

1. 在事件列表和告警中心查看异常。
2. 在动作执行中使用当前已实现的IP放行/回滚；其他动作执行器返回501，不能据列表认定封禁/限速已生效。
3. 在态势感知页查看地图、访问趋势和风险分布。
