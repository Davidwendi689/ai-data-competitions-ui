### 4.3 核心接口的最小范围（Web 条目）

| 核心能力 | 实现选择 | 必须稳定的接口行为 |
| --- | --- | --- |
| 请求 | `requestJson`（建议名）复用 `fetchWithCsrf`，支持 `AbortSignal` | 区分 HTTP 失败、非 JSON、空响应、主动取消；不自动重试写入，不自动把失败转为 `[]`，不强制弹 toast |
| 列表 | 扩展 `AdminDataTable` 现有 props | 业务提供 columns/操作/工具栏；本地和服务端分页明确互斥；筛选回第一页、稳定行 ID、总数和错误状态正确 |
| 表单与内容编辑 | RHF/Zod、RichTextField、既有上传组件 | 一个表单只保有一个状态所有者；上传失败不更新已保存引用；富文本 HTML 的旧内容与清洗语义保持 |

<!-- source-lines: 175-176; sha256-lf: fc0d32394d5f1445819dd3450107c3dd8ba05227376cc75bf40144b0eb6c917b -->
请求函数先在一个模块试用，再迁移第二个调用方验证复用价值。全部站内写请求迁移且浏览器验证后，才能评估退役 `SecurityFetchProvider` 的全局 fetch 修改；过渡期不得提前移除 CSRF 保护。下载、上传 FormData、Server Action 和流式接口各自保留适配，不强塞进 JSON 返回类型。

### R3：共享 UI 和请求处理接入两个真实消费者

**交付目标**：比赛管理和通知管理使用同一请求/表格底座，报名表保有单一表单状态；页面不再承担大量 DTO 转换和业务规则。

- JSON 请求函数基于现有 fetchWithCsrf，处理 HTTP 错误、无效 JSON、空响应与 AbortSignal；不自动重试写入、不吞错误返回空列表、不强制弹 toast。
- 先迁移一个列表，再迁移第二个验证接口；只有多处真实请求生命周期相同时才抽 Hook，不创建万能 useCrud。
- 扩展现有 AdminDataTable：受控分页/总数、稳定行 ID、工具栏/业务操作、loading/error/empty。完整数据本地分页和远程分页两种模式明确互斥。
- 比赛页提取默认值/表单值映射和编辑组件，日期复用现有工具；业务字段仍是明确代码，不做 JSON 表单引擎。
- 报名表的草稿和成员/教师数组共享一个 RHF control。草稿成功提交才清理，失败保留；草稿中的个人信息、跨账号隔离与保留期另列安全行为，不在抽取代码时扩张或清空。
- 导航使用共同能力与少量配置；元信息里放 href/label/所需能力，不放所有业务 handler 和服务端实现。

**通过条件**：编辑 A 后打开 B 不串值；快速筛选时旧响应不覆盖新数据；主动取消不弹失败 toast；表格页内数量不冒充总数；上传/提交失败不丢输入。浏览器覆盖创建/编辑/取消/失败重试、窄屏关键操作以及报名主链路。

**回退**：按页面迁移，API 和组件对外入口保持兼容；全部站内写请求确认迁移前保留 SecurityFetchProvider 的 CSRF 兼容，不提前移除保护。

### 实施记录：R3

- 比赛、通知共享 CSRF JSON 请求函数、可取消资源读取和表格状态；HTTP/解析失败不伪装空数据，写入不重试。会话 401 与服务失败分开，现有消费者处理异常。导航按能力元信息过滤，服务端仍独立授权。
- 比赛编辑器按打开动作重建状态，详情请求取消后不回写；标量、时间及嵌套列表转换集中于编辑器。修复清空可选字段被省略导致旧值残留，空字符串沿现有 PATCH 契约清空。
- 表格区分完整列表本地分页与受控远程分页，远程使用服务端 rowCount 且不二次分页或对单页排序。两个现有页面仍为完整列表，未声称后端分页已上线。
- 报名默认值/草稿恢复统一 RHF reset，空成员/老师数组正确清空；保留原草稿 key 和个人信息策略。成功提交才清理，失败保留输入。
- 固定工具链 lint、源码/测试类型、26 权限、22 单测、production build 与 6 项真实 HTTP 安全回归通过。渲染测试覆盖远程第 2 页/总数及失败/空状态；请求测试覆盖取消、坏 JSON、网络失败无重试和 CSRF。
- 本地随机 PostgreSQL + 合成账号浏览器验收：比赛创建、A/B 编辑隔离、服务端拒绝保留输入后重试成功、清空地点实际为 SQL NULL；通知创建和 390px 窄屏编辑保存；报名空数组草稿恢复、邮箱归属拒绝保留输入、修正后提交成功。未使用生产数据。慢网络快速切换仅有取消逻辑/单测证据，未模拟浏览器网络节流。
