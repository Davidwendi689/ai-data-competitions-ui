# 三、第二层：数据看板埋点层

## 目标

这一层负责业务分析，同时收集低可信客户端风险信号。

包括：

```text
页面访问
按钮点击
搜索
报名
提交问题
后台页面访问
安全中心 tab 切换
用户行为路径
```

同时允许轻量记录：

```text
DevTools 打开
控制台疑似调试
异常客户端环境
```

## 反调试策略

```text
轻量反调试。
只检测，不阻断。
只低频上报，不影响数据看板。
```

允许的检测：

```text
1. DevTools 尺寸差检测
2. 低频 debugger 时间差检测
3. session 级别一次性上报
```

禁止：

```text
1. 死循环
2. debugger 无限循环
3. 页面跳转
4. 清空 DOM
5. 禁止页面继续执行
6. 把 devtools 事件写进 analytics_events
```

## 数据隔离

必须分两张表：

```text
analytics_events：业务数据看板
security_events：安全中心
```

不要把反调试事件写到业务看板里。

正确做法：

```text
用户点击按钮
  ↓
analytics_events

用户打开 DevTools
  ↓
security_events
```

## 前端文件建议

```text
src/lib/analytics/track-event.ts
src/lib/security/client-security-event.ts
src/components/security/LightAntiDebugClient.tsx
```

## 事件类型

轻量反调试只写：

```text
security.client.devtools_detected
```

severity：

```text
low
```

metadata：

```json
{
  "policy": "light",
  "detection": "viewport_delta",
  "path": "/admin/security/events",
  "tab": "events"
}
```

## 适用页面

```text
/admin/security/events
/admin/security/alerts
/admin/dashboard
/admin/analytics
普通后台数据看板页面
```

## 节流规则

```text
同一 session 最多上报 1 次
同一路径 30 分钟最多上报 1 次
同一用户每天最多 5 次
```

# 四、第三层：敏感前端交互层

## 目标

这一层保护高风险操作，不让反调试破坏系统，但增加安全摩擦。

适用页面：

```text
/admin/security/actions
/admin/users
/admin/permissions
/admin/competitions
/admin/uploads
```

尤其是：

```text
封禁 IP
解除封禁 IP
限制用户上传
标记风险用户
强制用户重新登录
修改用户角色
删除内容
修改比赛配置
```

## 反调试策略

```text
中等强度反调试。
检测 + 安全埋点 + 二次确认。
不使用死循环。
```

检测到调试行为后：

```text
1. 写入 security_events
2. 页面不崩溃
3. 敏感动作执行前增加二次确认
4. 高危动作要求重新验证管理员身份
5. 后端 action metadata 记录 client_debug_detected=true
```

## 不建议死循环

不要做：

```js
while (true) {}
```

原因：

```text
1. 没有审计记录。
2. 无法判断误杀。
3. 会破坏页面和浏览器。
4. 会影响你自己的线上排障。
5. 不能形成安全中心闭环。
```

替代做法：

```text
软阻断 + 安全埋点 + 二次确认
```

例如：

```text
检测到 DevTools
  ↓
记录 security.client.devtools_detected
  ↓
执行动作时弹窗：
“检测到当前环境存在调试行为，请输入 BLOCK 确认继续执行”
  ↓
后端记录动作执行上下文
```

## 事件类型

```text
security.client.devtools_detected
security.client.sensitive_action_debug_context
security.action.confirmation_required
security.action.executed
security.action.rollback
```

## severity

```text
普通敏感页 DevTools：medium
DevTools + 执行动作：high
DevTools + 权限拒绝：high
DevTools + 高频失败：critical
```

```text
- 不阻断

- page_view
- button_click
- search

可信度：
- 业务埋点中等
- 客户端安全信号低
```

```text
第三层：敏感前端交互层

- security_events
```

# 十、反调试策略代码口径

## policy

```ts
export type AntiDebugPolicy = "off" | "light" | "sensitive";

export function getAntiDebugPolicy(pathname: string): AntiDebugPolicy {
  if (pathname === "/admin/security/events") return "light";
  if (pathname === "/admin/security/alerts") return "light";
  if (pathname === "/admin/security/actions") return "sensitive";

  if (pathname.startsWith("/admin/users")) return "sensitive";
  if (pathname.startsWith("/admin/permissions")) return "sensitive";

  return "off";
}
```

## light

```text
检测到 DevTools：
- 写 security_events
- 不弹窗
- 不阻断
```

## sensitive

```text
检测到 DevTools：
- 写 security_events
- 设置 sessionStorage 标记
- 执行动作时二次确认
- 后端记录 metadata.client_debug_detected=true
```
