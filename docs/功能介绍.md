# 功能介绍

2026-10-11 本地合成浏览器验收通过：后台新建→真实PNG封面上传→草稿保存/重开→直接发布→已发布编辑→匿名公开新版本→下线后404；旧 me 编辑深链重定向到唯一后台。连续空格、Enter、中文文本、粗体选区、纯文本粘贴、Undo/Redo已验证，320px编辑器与375px公开页无横向溢出。API/Web HTTP36项、API数据库62项、Web55项自动回归见对应栈顶PR；真实操作系统IME、S3桶、微信/手机真机和生产切换未验收。

社团管理操作：从“内容工作台”进入已授权社团，新建后先上传封面再保存草稿或保存并发布；已发布文章的“保存并更新公开内容”立即更新公开页，已下线文章保存仍保持私有，重新发布需明确点击。遇到409保留当前输入，重新加载核对服务端新版本；发布失败可复用已保存草稿重试，内容类型在创建成功后即锁定。授权由全局管理员在用户管理独立配置，联系方式设置与已发布内容治理各按API能力显示。

社团操作按钮读取 API allowedActions；写请求仍由 API 重新鉴权并比较 revision。旧个人中心/新后台未登录访问保留经过 Web proxy 覆写的内部路径 callback，不信任浏览器自带路径 header。新增源代码回归覆盖上传中阻塞、发布失败后的同草稿重试、本地编辑回声/组合输入/晚到数据不覆盖、纯文本粘贴转义；这些不是操作系统 IME 实测。

富文本输入由浏览器 DOM 持有：本地 value 回声、IME、blur 和格式操作不重写 innerHTML；外部晚到值不覆盖脏内容，切换文章通过 editorKey 重建。工具栏缓存编辑器内选区，粘贴纯文本转义尖括号，格式/安全清洗仍在粘贴、API 保存和展示边界执行。自动模拟 composition 不代表真实操作系统 IME 或手机验收。

2026-10-11 社团统一工作台：`/admin/clubs/[slug]/contents` 承载列表、新建与编辑，API 返回实际可管理范围；纯社团管理员访问 `/admin` 自动进入工作台。个人中心四类旧链接先登录/核对授权及内容归属，再临时重定向；旧审核页不再呈现审批。用户授权配置归 `/admin/users`，联系方式设置仅全局管理员可见，不向 scoped 内容管理员读取管理员邮箱。business_admin 通过治理页强制下线，不能自动获得全站编辑权。生产/真机验收尚未执行。


社团内容采用直接发布，已发布可直接保存且保持公开；下线内容保存保持私有。Web 携带 API revision，冲突保留当前输入并提示重新核对；发布失败保留已存草稿与版本，同内容重试发布不会重复新建。旧审核菜单/工作台迁移在入口层收口。

社团表单要求真实上传封面；上传中禁用保存/发布并阻止键盘提交。替换失败保留旧封面，字段错误保留正文并显示在封面区域。API 对合并后的封面与图片作最终对象/归属/解码校验。

2026-10-11：用户管理增加社团授权勾选，独立提交 grant/revoke 与当前赋权 ID，保留原有效期显示；保存平台/比赛权限不会隐式撤销社团授权。后台壳读取 API capability，社团工作台与其它管理功能分别授权。图片清洗及公开素材代理支持规范自定义存储前缀；实际 prefix、归属及可见性仍由 API 验证。

本仓承载完整 Web，数据与命令经 API。下表描述当前源码入口和限制；不代表浏览器或生产流程已验收。

## 当前功能

| 范围 | 页面/交互 | 当前限制 |
| --- | --- | --- |
| 公开门户 | 首页、比赛列表/详情、通知、社团、奖状、名人堂、人物/经验、网站团队 | 公开 DTO 由 SSR 私网读取；比赛每页 30 条，不开放浏览器 JSON；无 Mock fallback，团队资料由代码维护 |
| 认证 | 学生/教师注册、登录、找回/重置密码 | public 模式不接真实身份；身份与会话签名由 API 处理 |
| 报名 | 动态表单、团队成员、提交、本人记录、编辑/撤回与审核时间线 | 时间、状态、编号、归属和事务由 API 校验 |
| 问答 | 比赛问答、分页、回答、树形评论、采纳和治理 | 操作能力由 API 当前身份返回；Markdown 不启用原始 HTML |
| 个人工作台 | 资料、成果、经验与名人堂 | 经验/名人堂需管理员邀请；旧社团链接鉴权后转到后台工作台 |
| 业务管理 | 比赛、报名审核/导出、用户、通知、奖状/经验审核、名人堂和社团 | 菜单按 API 能力展示，具体接口再做服务端对象授权 |
| 固定分析 | 指标、趋势、漏斗与风险 | SQL 查询台及其执行能力已删除；指标不表示因果结论 |
| 安全中心 | 事件、告警、动作与态势地图 | 实际执行器在 API，目前只有 IP 放行/回滚；展示不等于动作生效 |

完整路由见[页面结构](./页面结构与用户流程.md)，共享组件与自动回归见[代码组织](./代码组织与组件约定.md)。

## 目标与实现差距

本分支已实现 [API #70](https://github.com/gduf-community/competition-Q-A-website/issues/70)配套的统一后台入口、封面必传、直接发布与已发布编辑。存量状态迁移工具及本地演练由 API 交付；生产迁移与切换、真实存储、操作系统输入法和手机浏览器仍待验收，不能以本地通过关闭整个改版任务。

默认 public 预览只读，不接受私有写入或身份 Cookie；Web 使用独立服务凭据，不持有数据库、认证签名或存储管理凭据。[环境说明](./开发环境与HTTP边界.md)列出运行与真实部署边界。
