## 技术下限与实测分开

当前 package.json 未单独声明 Browserslist。Next.js 16.3.8、React 19.2.3、Tailwind 4.1.18 和实际 API/CSS 一起决定下限；不能继承历史全栈文档的 Android >=8、Safari 15+ 为本仓已验证承诺。

官方安装/升级说明可供制定测试范围：[Next.js 浏览器支持](https://nextjs.org/docs/app/getting-started/installation#supported-browsers)、[Tailwind v4 浏览器要求](https://tailwindcss.com/docs/upgrade-guide#browser-requirements)。它们是供应方要求，和平台真机验证是两类证据；最终记录系统、浏览器版本与实际引擎，不把浏览器品牌或 OS 版本当作相同引擎。

## 已有兼容处理

JSON 客户端检查 signal.aborted，兼容缺失 reason；表单沿既有默认值工厂，不要求 structuredClone。编辑器有组合输入保护、选区保留和晚到数据处理；自动测试模拟 composition 不代表 OS 输入法通过。

2026-10-11 有合成 Chromium 的搜索/社团回归记录及 320/375/390px 检查，精确范围见[测试与验收](./测试与验收.md)。它们不代替 Safari、微信、手机键盘、真实下载、对象桶或生产入口验证。

## 每轮验收记录

记录合成环境、精确 Web/API SHA、public/trusted、设备/OS/浏览器/引擎与视口、网络条件、用例、结果、脱敏证据和未测原因。先标明待测，再按实际结果填写；浏览器模拟、自动化 WebKit 和真实 Safari 分开。

1. 375/390/414/768px 及桌面检查导航、长文本、表格/弹层；320px 或放大重排检查正文无溢出，二维表格可内部滚动。
2. 登录/刷新会话、报名必填/团队/重复提交、问答、上传失败重试、下载文件内容/落盘与通知已读分别核验。
3. 编辑器测试真实中文候选、组合期 Enter、光标/格式、粘贴、撤销/重做、移动键盘、保存重开与冲突保留。
