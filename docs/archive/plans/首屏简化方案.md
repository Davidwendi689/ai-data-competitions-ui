我的建议是：**不要把“作品墙”当成一个新增大模块，而是把它并入“荣誉展示链路”里，形成 `作品墙 → 名人堂` 的连续叙事。** 首页主线仍然服务“找比赛、看通知、报名”，作品墙只承担信任背书和视觉记忆点。

首页重排计划如下：

```tsx
<NewHero />              // 首屏：只承担定位、主入口、当前重点赛事
<NewFeatured />          // 第一内容层：近期可参与赛事
<NewQuickLinks />        // 轻量快捷入口：通知、我的报名、社团入口
<HonorShowcase />        // 作品墙 + 名人堂整合区
<HomeClubPreviewLite />  // 轻量社团生态入口
<NewCta />
```

如果想更收敛，最终版可以压成：

```tsx
<NewHero />
<NewFeatured />
<HonorShowcase />
<HomeClubPreviewLite />
<NewCta />
```

其中 `HonorShowcase` 内部结构是：

```tsx
<section id="honor-showcase">
  <AwardWall />       // 奖状作品墙，动态视觉区
  <NewHallOfFame />   // 名人堂，人物背书区
</section>
```

这样作品墙不是硬插在名人堂上方，而是成为名人堂的前置证据：**先看成果，再看人。**

首屏 `NewHero` 的调整计划：

保留右侧“赛事情报窗口”，但左侧三枚功能小卡需要更克制。现在 Hero 左侧已经有“公告集中查看、报名进度可追踪、重点赛事优先呈现”，下面又接 `NewStats`，所以功能重复。建议 Hero 只保留两个主按钮：

```txt
查看全部比赛
查看通知公告 / 查看我的报名
```

右侧继续展示 1 个主推赛事 + 2 个次级赛事，但不要再让首屏下方马上出现厚重统计卡。首屏目标要非常单一：**告诉用户这是竞赛服务平台，并把用户导向比赛与报名。**

`NewStats` 的调整计划：

现有 `NewStats` 不应继续作为四张大玻璃卡片独立占一屏。它应该改成轻量快捷入口，放在 `NewFeatured` 后面，或者直接并入 Hero 下方。

从：

```tsx
<NewStats />
```

改成：

```tsx
<NewQuickLinks />
```

视觉形态建议是“一行轻量入口”，不是大卡片：

```txt
报名中赛事  |  通知中心  |  我的报名  |  四大社团
```

每个入口只保留图标、短标题、数量/状态，不再放长描述。这样既保留功能入口，又不会和 Hero、Featured 争主视觉。

`NewFeatured` 的调整计划：

`NewFeatured` 应提前到 `NewStats` 前面。理由是首页第一内容层应该直接承接首屏的“找比赛”任务。你之前判断对了：Hero 右侧已经展示重点赛事，但这不是问题，问题是后面又接大统计卡再接赛事卡，路径断了。正确顺序应该是：

```tsx
<NewHero />
<NewFeatured />
<NewQuickLinks />
```

这样用户从首屏看到赛事窗口，往下就是更多重点赛事，路径自然。

作品墙 `AwardWall` 的定位计划：

作品墙放在名人堂上方，但不要做成“又一个大标题 + 大段介绍 + 六张大卡”的厚模块。它应该更像“动态荣誉带 / 证书展廊”。

推荐结构：

```tsx
<HonorShowcase>
  <AwardWallCompact />
  <NewHallOfFameCompact />
</HonorShowcase>
```

文案层级建议：

```txt
荣誉展示
从奖项成果到优秀参赛者，记录学院竞赛成长轨迹。
```

作品墙标题不宜写得太大，不要和“重点赛事”“名人堂”同级争夺注意力。可以用：

```txt
奖状作品墙
代表性获奖证书与竞赛成果
```

动态形式建议采用“滚动展开 + 悬停聚焦 + 错层网格”，不要用横向 Marquee。原因是当前名人堂已经用 Marquee，如果作品墙也横向移动，两个连续模块会形成重复动效，首页会更乱。

作品墙视觉可以参考开源方案的思想：

1. **Codrops Sticky Grid Scroll**：适合参考“sticky + scroll-driven image grid”，作品墙随滚动展开，交互不是简单移动。
2. **Codrops Scroll3DGrid**：适合参考“透视网格 + 滚动变化”，但首页不要做得太 3D，否则会压过平台属性。
3. **React Bits Flying Posters / Dome Gallery**：适合参考海报墙形式，但许可证和视觉风格都要谨慎，不能把官网做成炫技组件展。

最终推荐是：**借鉴 Codrops Sticky Grid Scroll 的滚动网格逻辑，但用现有 Framer Motion 自己实现轻量版。**

名人堂 `NewHallOfFame` 的调整计划：

名人堂需要简化。现在名人堂是独立大模块，标题、按钮、分割线、Marquee 都比较完整。如果上方加入作品墙，名人堂就不应该继续保持同样重量。

建议改成：

```txt
标题：竞赛达人风采
副标题：从获奖成果中看见真实的参赛路径
展示：只展示 6–8 位
交互：保留横向展示，但降低高度和背景复杂度
入口：更多名人
```

更好的做法是把名人堂从“独立大模块”降级为 `HonorShowcase` 的第二段。也就是说，不再让作品墙和名人堂各自拥有完整 section，而是共用一个 section 标题。

社团模块 `HomeClubPreview` 的调整计划：

社团模块应该下移到名人堂之后，并改轻。现在它是四张完整 SpotlightCard，和赛事卡、统计卡、名人堂卡一起出现，会显得首页每一层都在抢主角。

建议从：

```tsx
<HomeClubPreview clubs={clubsData} />
<NewHallOfFame />
```

改成：

```tsx
<HonorShowcase />
<HomeClubPreviewLite clubs={clubsData} />
```

社团轻量版只保留：

```txt
社团名称
短标签
一句方向
进入社团页
```

不要再展示大段 description，也不要每张卡都用明显 spotlight。社团是辅助生态，不是首页主转化路径。

最终首页信息优先级应是：

```txt
一级：找比赛、看赛事详情、报名
二级：通知、报名进度、我的报名
三级：奖状成果、优秀参赛者
四级：社团生态、培养支持
```

对应页面结构：

```tsx
<NewHero />
<NewFeatured />
<NewQuickLinks />
<HonorShowcase />
<HomeClubPreviewLite />
<NewCta />
```

如果你担心首页还是长，可以采用更狠版本：

```tsx
<NewHero />
<NewFeatured />
<HonorShowcase />
<NewCta />
```

然后把通知、我的报名、社团全部放到 Hero 按钮区和导航栏。这个版本最干净，但会牺牲一点门户完整性。

我的最终推荐版本是中间方案：

```tsx
<NewHero />
<NewFeatured />
<NewQuickLinks />
<HonorShowcase />
<HomeClubPreviewLite />
<NewCta />
```

它比当前结构更收敛，也给作品墙留了位置。关键不是“新增作品墙”，而是把首页从“大而全门户”改成“赛事主路径 + 荣誉背书 + 生态补充”。
