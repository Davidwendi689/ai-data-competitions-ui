# Web 代码组织与组件约定

当前栈为 Next.js 16 App Router、React 19、TypeScript 5、Tailwind CSS 4；准确版本与依赖以 [package.json](../package.json) 和锁文件为准。基础交互使用现有 Radix/shadcn 风格组件，表单用 React Hook Form/Zod，表格用 TanStack Table，图表用 Recharts/ECharts，动效沿现有 Framer Motion。不引入第二套 UI 体系或没有实际消费者的抽象。

| 入口 | 职责 |
| --- | --- |
| [src/app](../src/app) | 页面、布局、错误页与同源 BFF；`(auth)`/`(dashboard)` 为路由组 |
| [src/components](../src/components) | ui 基础组件及 competitions/admin/clubs/profile/security 等领域组件 |
| [src/hooks](../src/hooks) | 既有资源、侧栏等交互 hooks |
| [src/lib/contracts](../src/lib/contracts) | HTTP DTO 和即时校验契约，不能引入可信后端实现 |
| [src/lib/web-data.ts](../src/lib/web-data.ts) | SSR 的 API 数据适配；只消费 HTTP |
| [src/lib/http-client.ts](../src/lib/http-client.ts) | JSON 请求、CSRF、错误与取消；不自动重试业务写入 |
| [src/lib/security](../src/lib/security) | Web 安全头、CSRF、客户端展示与上报；最终授权/处置在 API |
| [tests](../tests) | 前端表单、列表、客户端、网关、边界与 runtime 打包回归 |

## 复用约定

## 搜索协议与迁移清单（Web #8 / #24，2026-10-11）

核对 Web main `3b7bba0` 与 API main `b22e5b7`。旧 issue 的全量比赛/无 GET 问答/SQL 查询台描述已过时；现有 SSR 分页和传输白名单继续使用。

| 入口 | 数据完整性与权限 | 本轮处理与排序 |
| --- | --- | --- |
| `/competitions` | API 公共投影，服务端分页；隐藏比赛不进入结果 | #27/#57 接 q/mode/page/pageSize；非空查询相关度优先，报名开始升序、ID兜底；默认最新年份 |
| 比赛选择器、首页比赛 | 专用选择/有界展示，不代表完整检索结果 | 保留旧 limit/offset 与 featured/recent 排序，不截成搜索第一页 |
| `/competitions/[id]/questions` | API 比赛作用域、排除 hidden、服务端分页 | #58 接统一参数；非空查询相关度优先，再置顶、时间降序、ID |
| `AdminDataTable` 内部搜索 | 调用者传入完整授权数组才允许内存匹配 | #26 使用纯核心字段匹配；manual 分页仍禁用本地过滤/排序 |
| 后台用户/报名表 | API 输出授权投影；搜索由 API 执行 | #59 保留原 keyword、脱敏邮箱/状态/角色别名和服务端 scope；敏感词不做公共 URL 分享 |
| 安全态势事件 | 当前载入的时间窗口/上限样本 | #26 标注当前已加载事件；仅本地匹配 path/maskedIp/reason/region，不声称全库搜索 |
| SQL 查询台 | 已删除 | 无迁移入口；不恢复源码或路由 |
| 奖项等级、角色、状态、扩展名 includes | 业务分类/授权判断 | 排除；不批量替换 |

冻结普通协议：`q/mode/page/pageSize`，默认 fuzzy/1/20，公共页长 1..50，offset 不超过 1,000,000。重复标量、非十进制正整数、未知模式/非法域筛选返回 `INVALID_QUERY`；raw/规范化 q 超过 256 UTF-16 units 返回 `QUERY_TOO_LONG`。旧 keyword 仅在入口适配，与 q 冲突拒绝。空查询保留筛选和域默认排序；超末页为空且 total 不变。

fuzzy：NFKC、首尾 trim、非 locale lower、内部空白折叠；exact 保留内部空白。字段独立匹配：完整/前缀/子串/全部 token/部分 token 为 100/80/60/40/20，乘静态字段权重并取最高字段。token 不跨字段拼接，数组不拼接；并列按域顺序和二进制 ID 排序。比赛字段 title/category/department 权重 10/5/3；问答 title/body 权重 10/3。原文不改写，摘要未纳入比赛召回。

#25 交付纯核心及合成 fixtures；#26 只迁完整数组/明确样本；#27 处理 IME、防抖、提交、清空和 URL；#57/#58 在 API 排名之后分页并保证 count/items 同快照；#59 保留后台 pg_trgm、敏感精确查询、授权与审计；#60 最后验证受限正则。历史/建议/热门/拼音/编辑距离/全站万能接口后置。Regex 在资源验收前明确返回 `UNSUPPORTED_SEARCH_MODE`，普通特殊字符始终按字面。

#25 的纯模块为 [search.ts](../src/lib/search.ts)，合成语义/排序/边界测试为 [search.test.ts](../tests/search.test.ts)，可独立运行 `pnpm test:search`。API 使用相同核心源文件与语义 fixtures；不导入框架、数据库、权限或服务器环境。内存适配器要求 `kind:complete` 和唯一 ID，先全局评分排序再分页；远程页不能作为完整源。

#26：`AdminDataTable` 内部完整数据过滤复用纯字段 matcher；external/manual 模式不做本地二次过滤。安全态势明确标注“搜索当前已加载事件”，只比较既有脱敏投影，保留样本原顺序。比赛已是 SSR 分页，不迁回内存；完整比赛集合的 memory 排名参照由 fixtures 验证。新普通匹配增加 NFKC、大小写和同字段 token 召回；现有结构化筛选/授权 includes 保留。

#27：公共表单使用 [SearchQueryForm](../src/components/shared/search-query-form.tsx) 和可独立测试的 [输入生命周期](../src/lib/search-input.ts)：250ms replace 防抖，显式提交/筛选/清空使用 push，IME 组合期不提交，清空聚焦输入，卸载取消 timer。首屏/Back/Forward 由 URL 恢复，并以完整 query/filter key 重建表单；默认最新年份被写入分享链接。服务端分页通过 App Router 的可取消导航和 SSR 恢复，复用既有 private HTTP 传输，不新增浏览器公共 JSON 入口。新提交重置 page，翻页保留条件；400 展示参数错误，API 故障沿现有 error/retry 边界。API #57 配套后完整匹配才在数据库执行，必须配对验收。

API #57 配套层将比赛 SSR 切到显式 `search=1`，默认每页20、最多50，q/mode/year/status/page/pageSize 经验证后转发。页码不截断，非法/重复状态年份显示可恢复错误；当前页只展示 API 结果，不在本地二次筛选。API 迁移0030及存量回填完成后再配对发布，缺失投影/超时沿已有错误页重试；生产验收另留证据。

本节冻结实施规则；实现、单元、数据库、浏览器、远程 CI 与生产验收分别记录，文档提交不表示后续实现已完成。

优先改现有组件与函数。通用 UI 不承载权限和业务状态机；领域组件按真实 HTTP DTO 组织。`AdminDataTable` 的加载、错误/重试与分页沿既有配置，远程分页不能再按页内数据伪装全量排序。`CompetitionEditor` 负责表单默认值与请求转换，父页负责读取和成功刷新。

`requestJSON` 与 `useJSONResource` 保留 CSRF、取消、错误和资源变更行为，反馈由业务页决定。表单提交中限制重复操作，失败保留输入；危险动作明确确认，提交结果仍以 API 为准。图片、上传和富文本遵守[HTTP 边界](./开发环境与HTTP边界.md)。
