# 技术选型与模板映射

本文描述完整平台产品与 Web 体验。物理拆分后，页面/组件/SSR/BFF 与浏览器配置归[唯一 Web](https://github.com/gduf-community/ai-data-competitions-ui)，本仓只保留可信 API；职责与证据见[运行拆分](https://github.com/gduf-community/competition-Q-A-website/blob/d9a789baed9f45ce033f97da5c627eb4cbcc8dee/docs/Web与API运行拆分.md)。

最后更新：2026-09-14

## 1. 当前技术基线

当前项目已经是仓库根目录下的正式 Next.js 单体应用，不再处于模板选型或双项目拼装阶段。

| 层次 | 当前选型 |
|:---|:---|
| 应用框架 | Next.js 16 App Router、React 19、TypeScript 5 |
| 样式与主题 | Tailwind CSS 4、shadcn/ui、Radix UI、next-themes |
| 表单与校验 | React Hook Form、Zod、`@hookform/resolvers` |
| 表格与交互 | TanStack Table、dnd-kit、Sonner |
| 图表 | Recharts；安全态势地图使用 ECharts |
| 动效 | Framer Motion，仅用于公开展示和必要的状态过渡 |
| 数据与鉴权 | PostgreSQL、Drizzle ORM、Auth.js |
| 文件与图片 | 本地/S3 存储驱动、Sharp、file-type |
| 内容渲染 | React Markdown、remark-gfm、sanitize-html |

准确版本以根目录 [package.json](https://github.com/gduf-community/competition-Q-A-website/blob/d9a789baed9f45ce033f97da5c627eb4cbcc8dee/package.json) 和锁文件为准，文档不重复维护完整版本号。当前工具链、命令、CI和运行边界见[工程模块](https://github.com/gduf-community/competition-Q-A-website/blob/d9a789baed9f45ce033f97da5c627eb4cbcc8dee/docs/modules/工程与发布.md)，模块调用链见[代码组织](https://github.com/gduf-community/competition-Q-A-website/blob/d9a789baed9f45ce033f97da5c627eb4cbcc8dee/docs/代码组织.md)。

## 2. 模板吸收状态

早期选型使用过 ShadcnStore Dashboard/Landing 与 Launch UI 作为结构和视觉参考。当前结论是：

- 正式源码只在根目录 `src/`、`public/`、`scripts/` 等项目目录继续演进。
- 模板已吸收的页面结构和组件已成为项目代码，不再把上游目录当作运行时依赖或第二套应用。
- 即使本地仍保留上游源码副本，也只可用于查阅；需要复用时应复制最小必要代码到根项目并按现行代码风格改造。
- 产品信息架构以竞赛、报名、审核、内容沉淀和安全治理为准，不能由模板演示页反向决定。

## 3. 当前落地边界

### 公开端

- 首页、比赛、报名、通知、问答、社团、奖状、名人堂、公开人物与经验文章均使用 App Router 页面。
- 展示增强可以使用轻量动效，但必须保留可读性、移动端可用性和业务 CTA 的优先级。

### 个人中心

- 承载报名跟踪、资料维护、成果、经验文章、名人堂资料和社团内容工作台。
- 权限和对象归属由服务端校验，页面显隐只用于改善体验。

### 管理台

- 使用统一 Dashboard 外壳，承载业务管理、数据分析、内容审核和安全中心。
- 后台不引入营销化动效；高权限工具必须沿用现有认证、作用域、限流、审计和响应头基线。

## 4. 依赖策略

- 优先复用已经安装且正在使用的依赖，不因上游模板或未来设想重复引入库。
- 新依赖必须对应明确的现行业务需求，并检查浏览器支持、包体积、服务端兼容性和维护成本。
- 不混入 Ant Design、MUI、Element、Mantine 等第二套完整 UI 体系。
- 日历当前仍是简版时间线；没有明确需求前不引入 FullCalendar。
- 富文本使用现有编辑、清洗和存储链路；没有迁移收益前不另起 Plate 等编辑器体系。
